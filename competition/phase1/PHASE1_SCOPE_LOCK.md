# Phase 1 Scope Lock

This file records the finite completion rule agreed for VeilGraph.

- Broad PII v5 is the frozen Phase-1 detector.
- TAB and ARI remain preserved as honest external evidence.
- ARI's failed predeclared quality gate is a documented limitation.
- Phase 1 does not require Broad PII v6/v7 solely to chase arbitrary new external benchmarks.
- Future accuracy changes are controlled later iterations and must preserve provenance.
- Phase 1 is considered complete after the green full regression and browser L4/L5 acceptance checks.
