# VeilGraph SIH26171 Public Release Boundary

The final competition release is the privacy-preserving browser-agent system described in the root
documentation and measured under `artifacts/sih26171/`.

Safe claims require the generated claim registry and final release manifest. In particular, VeilGraph
does not claim universal anonymity, zero unknown bugs, WebGPU validation when the validated runtime is
WASM, Firefox validation without a real recorded Firefox loop, or an organizer-issued SIH score.

The intended judge path is the controlled PrismCare workflow plus the generated evidence dashboard.
